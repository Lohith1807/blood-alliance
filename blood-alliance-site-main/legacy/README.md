# Blood Alliance - Clash of Clans Family

A premium landing page and CWL tracking system for the Blood Alliance clan family.

## Features
- **Premium UI**: Modern dark theme with glassmorphism and ambient glow effects.
- **Dynamic Clan List**: Fetches clan data from `clans.json` with a remote fallback.
- **CWL Player Tracker**: Real-time integration with Google Sheets (via Sheet2API) to track player registrations and clan assignments.
- **Universal Links**: Direct integration with Clash of Clans game links for profiles and clans.
- **Responsive Design**: Optimized for mobile, tablet, and desktop viewing.

## Tech Stack
- HTML5 / Vanilla CSS3
- JavaScript (ES6+)
- Google Fonts (Outfit & Bungee Inline)
- Sheet2API Integration

## How to Update Data
- **Clans**: Update the `clans.json` file in the root directory.
- **CWL Players**: The data is fetched live from the configured Sheet2API endpoint.
