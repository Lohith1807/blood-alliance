# Blood Alliance - React Platform

A modern, high-performance React application for the Blood Alliance clan family.

## Features
- **React-Powered**: Built with Vite and React for ultra-fast performance and clean component architecture.
- **Local Intel Protocol**: Removed external Sheet2API dependencies. All data (Clans & Players) is now managed via secure local JSON files in `src/data/`.
- **Premium UI/UX**:
    - **Framer Motion**: Smooth entry animations and layout transitions.
    - **Lucide Icons**: Professional vector icons for better accessibility and style.
    - **Glassmorphism**: Modern dark-mode aesthetics with ambient glow.
- **Advanced Filtering**: Instant search and squadron-based filtering in the CWL Tracker.

## Tech Stack
- **Framework**: React 18 (Vite)
- **Styling**: Vanilla CSS with Modern Variables
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Data Management**: Static JSON with React state/memoization

## Getting Started
1. `npm install`
2. `npm run dev`

## File Structure
- `src/components/`: Modular React components.
- `src/data/`: JSON data sources for Clans and players.
- `src/index.css`: Global design system and theme variables.
